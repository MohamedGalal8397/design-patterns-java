# design-patterns-java

GoF design patterns implemented in Java: creational, structural and behavioral.

**Stack:** Java, Maven

## Contents

Each folder is a small, self-contained exercise.

- `behavior`
  - `chain_reponsibility`
  - `mediator`
  - `observer`
  - `state`
  - `template`
- `creational`
  - `abstract`
  - `Builder`
  - `deep_copy`
  - `factory`
  - `prototype`
  - `shallow_copy`
  - `singleton`
- `structural`
  - `adapter`
  - `decorator`
  - `facade`
  - `proxy`

## Run

Open any exercise folder in IntelliJ IDEA (or run `mvn compile exec:java` for Maven ones) and run its `Main` class.
